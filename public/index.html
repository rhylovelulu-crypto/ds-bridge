手机 / 局域网使用指南

想在手机上用这个桥、不用一直守着电脑？按下面五步走。前提：手机和这台电脑连的是同一个 WiFi。
1
在电脑上用桌面模式（start.bat）登录过 DeepSeek 一次。已经登录过就跳过这步。
2
双击项目目录里的 start-server.bat —— 浏览器无头运行（不弹任何窗口），服务开放给局域网。之后电脑可以锁屏或最小化，服务照常跑。
3
手机浏览器打开 http://<电脑IP>:8788/（下面已自动填好本机地址），在「状态」页把 API Key 粘进输入框 —— 只需粘一次，手机浏览器会记住。
4
手机上的酒馆/客户端这样填：
Base URL：http://<电脑IP>:8788/v1
API Key：config.json 里的 sk-dsb-...
模型：deepseek-web（带思考用 deepseek-web-think）
5
第一次连接如果失败，是 Windows 防火墙拦了。在电脑上以管理员身份运行一次：
New-NetFirewallRule -DisplayName "ds-bridge" -Direction Inbound -LocalPort 8788 -Protocol TCP -Action Allow
本机局域网地址： 检测中… （手机打不开时优先检查：手机连的是不是这个 WiFi、防火墙是否放行）
想完全不开电脑？把整个目录拷到旧电脑 / NAS / 云服务器，装 Node 22+，设 DS_HEADLESS=1 和 DS_BRIDGE_HOST=0.0.0.0 跑 node server.mjs。登录态迁移：把用户目录下的 .ds-bridge-profile-cn（和 intl）整个拷过去即可，不用重新登录。

手机当服务器（Termux / Android）

让手机本身就是服务器：Termux 里跑 Node + Chromium，酒馆连手机本机 127.0.0.1:8788，电脑可以彻底关掉。
1
手机装 Termux。它就是一个普通安卓应用，不需要应用商店：
① 手机浏览器打开 https://f-droid.org/packages/com.termux/
② 往下滑，点「Download APK」，下载后点开安装（弹"未知来源"提示就选允许）
③ 注意别装错：Google Play 和 GitHub 上的版本都已停更，认准 F-Droid
2
把项目文件传到手机。放在哪都行，记住位置即可：
A. 电脑上把 ds-bridge 整个文件夹用微信/QQ/数据线传到手机。微信存的在 /sdcard/Download/微信/ 或 /sdcard/Pictures/WeiXin/，QQ 在 /sdcard/Download/QQ/，数据线放哪是哪——不确定就打开手机「文件管理」App 搜 ds-bridge
B. Termux 里直接联网下载（不依赖传输，放哪都固定）：pkg install curl -y 然后 curl -L https://gh-proxy.com/https://github.com/misa1ink/ds-bridge/archive/refs/heads/main.tar.gz | tar -xz （会解压出 ds-bridge-main 文件夹，路径就是 ~/ds-bridge-main）
3
打开 Termux，先拉唤醒锁防杀后台：下拉通知栏 → Termux 通知 → Acquire wakelock。然后一条命令安装启动——文件放哪都无所谓，路径照你实际位置写即可，代码会自动装到 ~/ds-bridge：
bash /sdcard/Download/ds-bridge/termux-setup.sh
路径怎么写都不影响结果：脚本无论从哪运行，都把代码装到固定位置 ~/ds-bridge，以后重启只用 bash ~/ds-bridge/termux-setup.sh --start，和原文件夹还在不在无关。
完全不想管路径？跳过传输，Termux 里直接在线装（两条命令）：
pkg install curl -y
curl -L https://gh-proxy.com/https://github.com/misa1ink/ds-bridge/archive/refs/heads/main.tar.gz | tar -xz && bash ~/ds-bridge-main/termux-setup.sh
找不到文件夹？find /sdcard -maxdepth 3 -name termux-setup.sh 2>/dev/null 搜出真实路径再 bash。
如果提示「Permission denied」访问 /sdcard，先执行 termux-setup-storage 并允许文件权限。
4
启动成功后（屏幕显示服务地址），手机浏览器打开 http://127.0.0.1:8788/，「状态」页复制 API Key。酒馆/客户端里：
Base URL：http://127.0.0.1:8788/v1 · 模型：deepseek-web
5
登录 DeepSeek（三选一，推荐 A）：
A. 用电脑的登录态：电脑已登录过的话，把电脑用户目录（C:\Users\你的用户名\）下的 .ds-bridge-profile-cn 文件夹传到手机（同样放哪都行，比如下载目录），Termux 里执行 termux-setup-storage 后（假设放在下载目录）：cp -r /sdcard/Download/.ds-bridge-profile-cn ~/——放别的位置就把路径换掉；找不到就在手机文件管理里确认实际位置再改路径。重启脚本即已登录
B. 控制台点「打开 DeepSeek 登录窗口」：无头模式后台建登录标签页，画面看不到，执行后等 1 分钟再点「检查登录状态」，若你在该浏览器 profile 上曾经登录过即会变绿
C. 每次都要在手机上重新扫码的话，体验较差，不推荐
常见问题：后台被杀 → 每次启动前拉 wakelock，或在系统设置里给 Termux 关掉电池优化； chromium 打不开 → Termux 上必须用 pkg install chromium 装的版本，不能用安卓版 Chrome； 局域网访问 → 手机和别的设备同一 WiFi，地址是手机的局域网 IP:8788； 忘了重启命令 → 永远是 bash ~/ds-bridge/termux-setup.sh --start。
