# ds-bridge 手机使用教程（Termux 完整版）

> 让你的手机变成一台「DeepSeek 转 OpenAI 接口」的服务器：装好后手机自己就是服务器，
> 酒馆/SillyTavern 直接连手机本机，电脑可以彻底关掉。
>
> 全程只需要装一个普通安卓应用（Termux），不需要 root、不需要破解、不需要编程基础。

---

## 这是什么

ds-bridge 把 DeepSeek 网页端的会话包装成 OpenAI 兼容接口（`/v1/chat/completions`、
`/v1/table/fill`），免费、不走官方 API 计费。在手机上装好之后：

- 酒馆数据库插件的填表请求直接打到你手机上，不用开电脑
- 登录态保存在手机本地，长期有效
- 断网重启也不怕，一条命令拉起来

---

## 开始之前

| 需要什么 | 说明 |
|---|---|
| 一台 Android 手机 | Android 7+，预留 1GB 存储空间 |
| Termux | 下面第 1 步装，唯一要装的 App |
| 一个 DeepSeek 账号 | 手机号或微信登录的那个 |
| 网络能访问 DeepSeek | 能正常打开 chat.deepseek.com 即可 |

**关于 Termux**：它就是一个普通的终端模拟器 App（类似电脑上的命令行窗口），
不是什么特殊系统。只需从 F-Droid 下载 APK 安装，不用 root，用完可以随时卸载
（卸载 = 完全清除，不留任何残留）。

---

## 第 1 步：安装 Termux（2 分钟）

1. 手机浏览器打开：<https://f-droid.org/packages/com.termux/>
2. 往下滑到「Versions」，点最新版本的 **Download APK**
3. 下载完成后点开安装；弹出「未知来源应用」提示时选 **允许**
4. 装完打开，看到一个黑底白字的窗口就对了

> ⚠️ 认准 F-Droid。Google Play 和 GitHub Releases 上的 Termux 都已停更，
> 装了会有各种包管理错误。

---

## 第 2 步：拿到项目文件（二选一）

**方式 A：电脑传过去（已有项目文件夹的选这个）**

把电脑上的 `ds-bridge` 整个文件夹通过微信 / QQ / 数据线 / 蓝牙传到手机。
放哪都行——微信的文件在 `/sdcard/Download/微信/`，QQ 在 `/sdcard/Download/QQ/`，
不确定就打开手机「文件管理」App 搜 `ds-bridge`。

**方式 B：Termux 里直接在线下载（不想传文件的选这个）**

打开 Termux，粘贴这三行（一行一执行；Termux 默认没装 git/curl，
第一条命令就是装它们，报「The program git is not installed」就是这个原因）：

```bash
pkg install git curl -y
git clone https://gh-proxy.com/https://github.com/rhylovelulu-crypto/ds-bridge.git
cd ds-bridge
```

如果不想装 git，用 curl 拉压缩包也一样：

```bash
pkg install curl -y
curl -L https://gh-proxy.com/https://github.com/rhylovelulu-crypto/ds-bridge/archive/refs/heads/main.tar.gz | tar -xz
cd ds-bridge-main
```

会解压出一个项目文件夹。

> 两种方式效果完全一样。脚本不挑位置——无论文件夹在手机哪里，安装时都会
> 自动把代码归位到 `~/ds-bridge`，后续命令永远是同一条。

---

## 第 3 步：一键安装并启动（5-10 分钟，主要是下载）

1. 打开 Termux
2. **先拉唤醒锁**（防止后台被杀）：下拉通知栏 → 找到 Termux 的常驻通知 → 点 **Acquire wakelock**
3. 执行安装脚本——路径按你第 2 步实际放的位置写：

```bash
# 方式 A（文件夹在下载目录的示例）：
termux-setup-storage          # 弹出文件权限请求，点允许（只需一次）
bash /sdcard/Download/ds-bridge/termux-setup.sh

# 方式 B（在线下载的）：
bash ~/ds-bridge-main/termux-setup.sh
```

脚本会自动完成：

- 安装 Node.js 和 Chromium（约 200MB，取决于网速，耐心等）
- 把代码归位到 `~/ds-bridge`
- 生成 `config.json` 和 API Key（**屏幕上会打印出来，复制保存**）
- 以无头模式启动服务

看到下面这样的输出就是成功了：

```
[ds-bridge] ===========================================
[ds-bridge]  服务地址（本机）   http://127.0.0.1:8788/v1
[ds-bridge]  局域网             http://<手机IP>:8788/v1
[ds-bridge]  酒馆填上面任意一个 + API Key 即可
[ds-bridge] ===========================================
```

> 找不到文件夹？在 Termux 里执行
> `find /sdcard -maxdepth 3 -name termux-setup.sh 2>/dev/null`
> 会打印出真实路径，然后 `bash <打印出来的路径>`。
>
> 提示 Permission denied？先执行 `termux-setup-storage` 允许文件权限。

**这个窗口不要关**——Termux 窗口开着 = 服务在跑。可以切到别的 App，但别从
最近任务里划掉 Termux。

---

## 第 4 步：登录 DeepSeek（推荐用电脑登录态，免扫码）

**方式 A：从电脑迁移登录态（最快，推荐）**

如果电脑上的 ds-bridge 已经登录过（登录页显示「已登录」）：

1. 电脑打开 `C:\Users\你的用户名\`，找到 `.ds-bridge-profile-cn`
   （隐藏文件夹，文件管理器开「显示隐藏项目」；文件资源管理器 → 查看 → 勾选「隐藏的项目」）
2. 把这个文件夹传到手机（微信文件传输助手 / 数据线都行）
3. 手机上执行（路径按实际存放位置改）：

```bash
termux-setup-storage          # 如果之前没执行过
cp -r /sdcard/Download/.ds-bridge-profile-cn ~/
```

4. 重启服务：

```bash
bash ~/ds-bridge/termux-setup.sh --start
```

5. 手机浏览器打开 <http://127.0.0.1:8788/> → 登录页 → 点「检查登录状态」
   → 显示「已登录」+ 登录身份（你的打码手机号）就完成了

**方式 B：手机上直接登录**

控制台登录页点「打开 DeepSeek 登录窗口」——无头模式下会在后台创建登录标签页，
**没有可见画面**。执行后等一分钟再点「检查登录状态」。如果一直是未登录，
用方式 A。

**方式 C：扫码**

在登录等待期间用另一台设备（电脑/平板）的浏览器打开手机控制台
（`http://<手机IP>:8788/`，同一 WiFi），点登录窗口按钮在电脑屏幕上扫码，
登录态会进手机的 profile。

---

## 第 5 步：接进酒馆 / SillyTavern

手机上打开 <http://127.0.0.1:8788/> → **状态** 页：

- **Base URL**：`http://127.0.0.1:8788/v1`
- **API Key**：从「API Key」一栏复制（安装时屏幕也打印过）
- **模型**：`deepseek-web`（带思考用 `deepseek-web-think`）

在酒馆里：API 选择 **Custom OpenAI**，粘贴上面三项。填表插件里把填表模型
指到同一端点，数据库填表走 `http://127.0.0.1:8788/v1/table/fill`（一次请求
填整行，比逐字段快几倍）。

预设/破限：控制台 **预设** 页拖入你的酒馆预设 JSON 或破限 txt，立即生效。

## 日常使用

| 操作 | 命令/做法 |
|---|---|
| 启动服务 | 打开 Termux → 拉唤醒锁 → `bash ~/ds-bridge/termux-setup.sh --start` |
| 停止服务 | Termux 窗口里按 `Ctrl+C`（音量下+C），或直接划掉 Termux |
| 查登录状态 | 控制台登录页「检查登录状态」，或看「登录身份」 |
| 退出登录 | 控制台登录页「退出登录」按钮 |
| 换账号 | 控制台「切换账号」，然后重新登录 |
| 改并发 | 编辑 `~/ds-bridge/config.json` 的 `concurrency`（手机建议 1-2） |

### 防止后台被杀（重要）

Android 激进省电是手机上跑服务最大的坑，三层防护都做上：

1. **每次启动前拉唤醒锁**：通知栏 Termux 通知 → Acquire wakelock
2. **关电池优化**：系统设置 → 应用 → Termux → 电池 → 改为「不受限制」
   （各品牌叫法不同：华为是「启动管理」关自动管理，小米是「省电策略 → 无限制」）
3. **Termux 加小部件或常驻通知**：有些系统会杀无通知的后台应用，
   Termux 的常驻通知本身就是保护

服务被杀了也不可怕——数据都在，重新执行启动命令即可，登录态不会丢。

## 局域网共享（可选）

服务默认绑 `0.0.0.0`，同一 WiFi 下的其他设备也能用：

- 手机查自己的 IP：Termux 里 `ifconfig wlan0`（或控制台首页自动显示）
- 其他设备访问：`http://<手机IP>:8788/v1` + 同一个 API Key
- 适合：手机当服务器、平板上的酒馆当客户端

> API Key 是唯一防线，别把 Key 发给别人；不共享时不用管，反正 Key 在 config.json 里。

## 常见问题

**`pkg install` 报错/超时** → 换镜像源：`sed -i 's@^\(deb.*stable main\)$@#\1\ndeb https://mirrors.tuna.tsinghua.edu.cn/termux/apt/termux-main stable main@' $PREFIX/etc/apt/sources.list` 然后重跑 `pkg update`。

**Node 或 chromium 装失败** → 确认是 F-Droid 版 Termux；重跑安装脚本，它会跳过已装的部分。

**`bash: /sdcard/...: No such file or directory`** → 路径写错了。用 `find /sdcard -maxdepth 3 -name termux-setup.sh 2>/dev/null` 找真实路径。

**服务启动了但浏览器报错** → 看 Termux 屏幕上的报错行。`no Edge/Chrome found` 说明 chromium 没装上，执行 `pkg install chromium`。

**手机重启后服务没了** → 正常，Android 不保活。重新执行启动命令即可。

**登录态丢失** → 只要没删 `~/.ds-bridge-profile-cn` 就不会丢。被误删就重新登录一次。

**酒馆连接被拒绝** → 确认 Termux 窗口还开着（服务在跑）、Base URL 是 `http://127.0.0.1:8788/v1`（酒馆跑在手机上时）。

**回复变成助手腔/说教** → 预设没导入。控制台「预设」页导入并启用破限预设。

**429 / 频率限制** → DeepSeek 网页端有频控，降低酒馆侧请求频率；`config.json` 的 `concurrency` 保持 1-2。

**想彻底卸载** → Termux 里 `rm -rf ~/ds-bridge ~/.ds-bridge-profile-cn`，再卸载 Termux App，无任何残留。

## 和电脑部署的关系

同一份代码，三种跑法，随便选、可以混用：

| 跑法 | 适合 | 启动方式 |
|---|---|---|
| 电脑桌面模式 | 平时在电脑上用 | 双击 `start.bat` |
| 电脑无头挂机 | 电脑当家庭服务器，手机连它 | 双击 `start-server.bat` |
| 手机 Termux（本教程） | 电脑彻底不开 | 上面的安装脚本 |

登录态互通：`.ds-bridge-profile-cn` 文件夹在哪台设备，登录就在哪台。
复制到新设备 = 登录态迁移，不用重新扫码。
