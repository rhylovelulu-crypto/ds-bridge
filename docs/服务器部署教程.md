# ds-bridge 云服务器部署教程

> 部署到一台国内云服务器（阿里云/腾讯云/华为云，Ubuntu 或 Debian），让手机、电脑、平板
> 在任何网络下都能用，电脑彻底不用开。
>
> 预计耗时：15-20 分钟。需要的只是一台最低配的云服务器（1核1G 够用，2核2G 更稳）。

---

## 开始之前

| 需要什么 | 说明 |
|---|---|
| 一台国内云服务器 | Ubuntu 22.04/24.04 或 Debian 11/12，最低配即可 |
| 能 SSH 登录 | 买了服务器后控制台有 Web 终端，或用本机 ssh 命令 |
| 安全组/防火墙权限 | 云控制台里放行一个 TCP 端口（下面用 8788） |
| DeepSeek 账号 | 已在电脑上登录过 ds-bridge 的最方便（登录态直接迁移） |

**架构一句话**：服务器上跑 `ds-bridge`（Node + 无头 Chromium），你的酒馆/客户端从
任何设备连 `http://服务器IP:8788/v1`，API Key 是唯一认证。

---

## 第 1 步：连上服务器，装基础依赖

SSH 登录后（或用云控制台的网页终端），一行搞定：

```bash
sudo apt update && sudo apt install -y curl git chromium ca-certificates
```

装 Node.js 22（Ubuntu 自带的 node 版本旧，用 NodeSource 源）：

```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
node -v   # 应显示 v22.x 或更高
```

> 换成阿里云/腾讯云内网镜像更快（可选）：
> `curl -fsSL https://deb.nodesource.com/setup_22.x | sed 's|nodesource.com|mirrors.aliyun.com/nodesource|g' | sudo bash -`

---

## 第 2 步：下载项目

```bash
cd ~
git clone https://github.com/rhylovelulu-crypto/ds-bridge.git
cd ds-bridge
```

GitHub 连不上就用镜像：

```bash
git clone https://gh-proxy.com/https://github.com/rhylovelulu-crypto/ds-bridge.git
cd ds-bridge
```

生成配置和 API Key：

```bash
node scripts/init-config.mjs
```

**屏幕会打印 API Key（`sk-dsb-...`），复制保存**——这是之后所有设备连桥的凭证。

---

## 第 3 步：迁移登录态（关键一步，免扫码）

DeepSeek 的登录态在电脑上 `.ds-bridge-profile-cn` 文件夹里。两个办法：

**办法 A：从电脑上传（推荐）**

在你电脑上（PowerShell）：

```powershell
# 打包登录态文件夹
cd $HOME
tar -czf profile-cn.tar.gz .ds-bridge-profile-cn
# 传到服务器（换成你的服务器 IP 和用户名）
scp profile-cn.tar.gz root@服务器IP:~/
```

在服务器上：

```bash
cd ~
tar -xzf profile-cn.tar.gz          # 解压出 .ds-bridge-profile-cn
# 无头浏览器默认用 root 的 home 找 profile；如果服务用其他用户跑，把文件夹放到那个用户的 home
```

**办法 B：不迁移，先登录再说**

跳过这步，直接启动后在「登录」页用 token 注入方式登录（见教程末尾「无电脑登录」）。

---

## 第 4 步：创建 systemd 服务（开机自启 + 挂掉自动拉起）

```bash
sudo tee /etc/systemd/system/ds-bridge.service > /dev/null <<'EOF'
[Unit]
Description=ds-bridge - DeepSeek web to OpenAI bridge
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/ds-bridge
Environment=DS_HEADLESS=1
Environment=DS_BRIDGE_HOST=0.0.0.0
Environment=DS_CONCURRENCY=2
ExecStart=/usr/bin/node /root/ds-bridge/server.mjs
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now ds-bridge
sudo systemctl status ds-bridge   # 看到 active (running) 即成功
```

> 如果项目不在 `/root/ds-bridge`，改上面的 `WorkingDirectory` 和 `ExecStart` 路径。
> `Restart=always` 意味着进程崩了 5 秒后自动拉起，登录态在磁盘上不会丢。

---

## 第 5 步：放行端口

**云控制台安全组**（这步必须在云厂商网页做，SSH 里改 iptables 没用）：

1. 打开云控制台 → 找到你的服务器 → 「安全组」/「防火墙」
2. 添加入站规则：**TCP 8788**，来源 `0.0.0.0/0`
3. 保存

验证（在任何设备上）：

```bash
curl http://服务器IP:8788/health
```

返回 `"ok":true` 就是通了。

---

## 第 6 步：在酒馆/客户端里用

| 项 | 值 |
|---|---|
| Base URL | `http://服务器IP:8788/v1` |
| API Key | 第 2 步保存的 `sk-dsb-...` |
| 模型 | `deepseek-web`（带思考：`deepseek-web-think`） |

任何网络、任何设备都能连——家里 WiFi、公司、流量，都一样。

预设/破限：打开 `http://服务器IP:8788/` → 预设页 → 拖入酒馆预设 JSON。

## 安全加固（公网部署必做）

API Key 是唯一防线，做到这三条才算安全：

**1. 确认 config.json 里有强 Key**（init-config 自动生成的是 48 位随机串，别手改成弱密码）：

```bash
cat ~/ds-bridge/config.json | grep -A2 apiKeys
```

**2. 换掉默认端口**（可选但推荐，避开扫描器）：编辑 config.json：

```json
{ "server": { "host": "0.0.0.0", "port": 18443 } }
```

同时改安全组放行新端口、systemd 里无需改动（端口读 config）。

**3. 上 HTTPS（强烈推荐）**：明文 HTTP 下 API Key 和内容都是裸奔。用 Caddy 两条命令搞定自动证书：

```bash
sudo apt install -y caddy
sudo tee /etc/caddy/Caddyfile > /dev/null <<'EOF'
你的域名.com {
    reverse_proxy 127.0.0.1:8788
}
EOF
sudo systemctl reload caddy
```

（需要一个域名，解析到服务器 IP；没有域名就保持 HTTP+强Key，能用但不够优雅）

之后酒馆里 Base URL 换成 `https://你的域名/v1`。

## 日常运维

```bash
sudo systemctl status ds-bridge    # 看状态
sudo systemctl restart ds-bridge   # 重启（改了 config.json 后）
sudo journalctl -u ds-bridge -f    # 看实时日志
sudo journalctl -u ds-bridge --since today   # 看今天的日志
```

服务器重启后服务自动拉起（systemd enable 过），不用管。

**登录过期**（DeepSeek 网页端会话一般能撑很久）：日志里出现大量 `deepseek 401` 时，
在电脑上登录一次 ds-bridge，重新打包含 token 的 profile 上传；或用下面的 token 注入方式。

## 无电脑登录（token 注入）

服务器上没有浏览器窗口，扫码登录不可见。两种方式：

**方式 A：手机抓 token 注入**

1. 手机浏览器开 `chat.deepseek.com` 登录
2. 按控制台「登录」页里的书签工具说明抓取 userToken（详细步骤写在页面上）
3. 打开 `http://服务器IP:8788/` → 登录页 → 把 token 粘进「注入登录态」输入框 → 点按钮
4. 「检查登录状态」变绿即完成

**方式 B：电脑登录后迁移 profile**

见第 3 步。迁移后 `sudo systemctl restart ds-bridge`。

## 常见问题

**`chromium` 安装不上** → Ubuntu 24.04 是 `chromium-browser`（snap 转发的坑），建议直接
装 Debian 12，或用 `apt install chromium-browser` 后确认 `/usr/bin/chromium-browser` 存在。
实在不行：`sudo apt install -y chromium`（Debian）/ 手动下载 Chrome for Testing 解压到 /usr/bin。

**`no Edge/Chrome found`** → 设环境变量：编辑 systemd 服务加
`Environment=DS_BROWSER=/usr/bin/chromium`，然后 `daemon-reload + restart`。

**服务器内存太小（1G）被 OOM 杀** → `DS_CONCURRENCY` 改成 1（systemd 文件里），加 1G swap：
`sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile`

**连不上 8788** → 90% 是安全组没放行（去云控制台看第 5 步）；其次检查
`curl http://127.0.0.1:8788/health` 在服务器本机通不通——本机通外网不通 = 安全组问题。

**中文乱码/界面字体方框** → 无头浏览器渲染不需要字体，不影响 API；但登录页截图需要：
`sudo apt install -y fonts-noto-cjk`。

**429 频率限制** → DeepSeek 网页端按账号限频，服务器上和其他设备共享同一个账号额度。
降低酒馆侧请求频率，`DS_CONCURRENCY` 保持 1-2。

**想彻底停掉** → `sudo systemctl disable --now ds-bridge`，不用了再删目录和 systemd 文件。
